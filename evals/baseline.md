# No-Guidance Baseline

Three fresh low-reasoning worker contexts routed eighteen representative scenarios before the plugin existed.

Observed failures that justified the policy:

- Delegated a one-line named component change instead of doing it directly.
- Delegated an exact-symbol lookup that one direct search could answer.
- Kept two unrelated broad domain searches in the primary agent instead of splitting them.
- Assigned primary reasoning to routine broad search and bounded four-file editing.

The skill addresses only demonstrated routing failures plus the user-approved hard safety boundaries. Full scenario expectations live in `scenarios.yaml`; evaluation dimensions live in `scorecard.md`.
